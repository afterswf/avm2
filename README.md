# avm2

This is [Mesmotronic](https://mesmotronic.com)'s fork of [awayfl/avm2](https://github.com/awayfl/avm2) for
[AfterSWF](https://github.com/afterswf/embed), published as [`@afterswf/avm2`](https://www.npmjs.com/package/@afterswf/avm2).
Its fixes are listed in [AfterSWF's README](https://github.com/afterswf/embed#more-advanced-as3-content).

It keeps the original package names in its imports, so install it, and any other afterswf packages you use, under
their original names with npm aliases:

```sh
npm install @awayfl/avm2@npm:@afterswf/avm2
```
